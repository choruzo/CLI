STRATUM

v0.4.0 · extensible · local-first · provider-agnostic

Un agente de línea de comandos sobre un loop ReAct (Reason → Act → Observe), con plan-and-execute, subagentes en paralelo, memoria persistente en tres capas y ejecución local o remota bajo guardas que no se pueden desactivar. Funciona con cualquier API OpenAI-compatible: Ollama, llama.cpp, vLLM, LiteLLM u OpenAI.
